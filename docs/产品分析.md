# 百工·筑（Zhu）产品分析

> 对标 Adobe InDesign · 2026-10-19 留档

## 要做什么

**核心职能**：面向印刷与数字出版的多页文档排版——将文字、图像、图形按版面规则编排为书册、杂志、手册、海报等，产出可印刷或发布的成品。

**必备核心能力**：

1. 页面体系：页面/跨页管理、页边距与分栏、母版（主页）
2. 文本排版：文本框与串接排文、段落/字符样式
3. 图文处理：图片置入与链接管理、基本图形绘制、图文绕排
4. 对象系统：图层、对齐分布、参考线与网格
5. 颜色色板
6. 导出 PDF/打印

**可后置高级能力**：长文档管理（目录、索引、脚注、书籍合订）、数据合并、增强表格、交互式 PDF/数字出版、脚本扩展、印前检查。

## 页面呈现样式

**主界面分区**：顶部菜单栏＋随选中对象变化的上下文选项栏；左侧工具箱；中央分页画布（可缩放平移、跨页显示）；右侧面板坞（页面、图层、段落/字符样式、色板、链接等，可停靠/折叠/组合）。

**关键页面/模式**：

- 页面面板：页面缩略图＋母版区，拖拽增删排序
- 母版编辑模式：统一定义页眉、页脚、页码
- 文本串接：框口溢流指示、链条关系可视
- 置入、颜色、导出/打印等对话框

**交互范式**：面板驱动与画布直接操纵结合；工具决定所建对象类型；属性随上下文切换；重度快捷键；所见即所得。

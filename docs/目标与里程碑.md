# 百工·筑（Zhu）目标与里程碑

> 本文回答「做到什么、分几步、每步怎么算数」。为什么做见
> [产品分析.md](产品分析.md)。状态快照：2026-10-22（文档 + CI 阶段，
> 无业务代码）。

## 开发目标

面向印刷与数字出版的多页排版工具（对标 InDesign 核心工作流）：
页面体系（跨页/分栏/母版）、文本排版（串接、样式）、图文绕排、
对象系统（图层/对齐/参考线）、色板、导出 PDF。**中文排版是一等
公民**（标点禁则、中西文混排间距、避头尾），文本 shaping 选型必须
以中文优先验证。外壳接入坊；渲染与 shaping 用 Rust/JS 生态库
（M0 评审）。

## 里程碑（每条以真实使用场景为准入）

- **M0 骨架**：Tauri 2 + React + 坊接入、文本 shaping/字体库选型
  （中文优先验证）、版面渲染方案评审（DOM vs Canvas）。
  准入：窗口内排出一行带样式的中英文混排文本（禁则与间距正确）。
- **M1 页面与文本框**：文档/跨页/分栏模型、文本框与串接（溢流
  指示）、基本字符与段落格式。
  准入：排出多页纯文字稿（含中文换行、标点禁则、避头尾）。
- **M2 图文与样式**：图片置入（链接式，不复制进文档）、图文绕排、
  段落/字符样式、色板。
  准入：排一本图文混排的小册子（A5、16 页级）。
- **M3 对象与长文档**：图层/对齐/参考线/网格、母版、页码/目录、
  表格基础。准入：产出数十页带目录、母版页码与表格的手册。
- **M4 导出与预检**：PDF 导出（自建管线 vs 借道纸的输出能力——
  届时与纸联合决策）、印刷标记、预检（字体嵌入/图片链接/溢流
  检查）。准入：印刷厂可直接使用的 PDF（预检零警告）。
- **M5+（后置池，按需触发）**：EPUB/交互式 PDF、数据合并、书籍
  合订、印前检查增强——产品分析「可后置」清单。

## 依赖与集群对齐

- 依赖坊：M0 起接入。
- 与纸协同：M4 的 PDF 导出可能复用纸已验证的 pdf-lib 经验或输出
  能力，届时两仓联合决策（纸 M8+ 备忘已记）。
- 不依赖冶。
- 排期建议：M0 的 shaping 中文验证尽早做（结论影响面大、工作量
  小），完整开发排在墨/陶前后择机启动。

## 原则

- 每个里程碑以真实使用场景为准入条件，不为了齐备而齐备。
- 排版正确性（断行/禁则/串接）优先于渲染性能；性能问题用真实
  长文档（百页级）压测，不用合成极限值。
